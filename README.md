# RSM 响应面建模 —— 出口光量子流量计补偿

用 **响应面法（RSM）** 建立「出口光量子流量计读数 → 首信流量计真值」的补偿模型，  
输出一套**可以直接抄进论文的显式公式**。

---

## 一、目录结构

```
RSM_functions/
├── rsm_main.py       ★ 主程序
├── rsm_config.py     ★ 参数配置
├── rsm_data.py         读取数据 + 清洗 + 按时间切分
├── rsm_model.py        RSM 模型：二次展开 + 岭回归 + 公式还原
├── rsm_metrics.py      评价指标：R² / 中位误差 / p90 误差
├── rsm_export.py       导出结果到 outputs 文件夹
└── outputs/            运行后自动生成
    ├── 预测结果_测试集.csv    逐点对比表
    ├── 指标汇总.csv          各数据集指标 + 补偿前后对比
    ├── 逐日误差.csv          逐日误差
    └── RSM显式公式.txt       
```

## 四、模型是什么

### 4.1 自变量（4 个）

| 变量     | 含义          | 单位      |
| ------ | ----------- | ------- |
| `√Δp`  | √(压差_出口光量子) | kPa^0.5 |
| `P`    | 压力_出口光量子    | MPa     |
| `T`    | 温度_出口光量子    | °C      |
| `Q_in` | 入口流量        | L/s     |

### 4.2 基函数（14 项 + 常数项）

```
一次项： √Δp,  P,  T,  Q_in
平方项： Δp,  P²,  T²,  Q_in²
交叉项： √Δp·P, √Δp·T, √Δp·Q_in, P·T, P·Q_in, T·Q_in
```

### 4.3 流程

```
二次多项式展开 (4 项 → 14 项)
        ↓
标准化（消除量纲差异，让岭回归惩罚公平）
        ↓
岭回归求解系数
        ↓
逆变换 → 还原成原始变量上的显式公式
```

## 五、预期结果

在 `某井` 数据上（925,562 个有效样本）：

| 数据集     | R²        | 中位误差      | p90 误差 |
| ------- | --------- | --------- | ------ |
| 训练集     | 0.684     | 1.80%     | 7.03%  |
| 验证集     | 0.292     | 1.19%     | 2.88%  |
| **测试集** | **0.565** | **1.07%** | 9.63%  |

逐日交叉验证（留一天）中位误差 **≈ 2.0%**，21 天里 19 天误差 < 5%。

### 5.1 补偿效果

主程序第 4 步会直接把**补偿前（原表读数）**&#x548C;**补偿后（RSM 预测）**&#x5E76;排打印：

| 指标       | 补偿前（原表光量子） | 补偿后（RSM）  | 提升        |
| -------- | ---------- | --------- | --------- |
| R²       | 0.516      | 0.565     | +0.049    |
| **中位误差** | **3.86%**  | **1.07%** | **3.6 倍** |
| 平均误差     | 10.99%     | 9.15%     | 1.2 倍     |
| p90 误差   | 17.06%     | 9.63%     | 1.8 倍     |

累计分布：误差 ≤2% 的样本从 **29.2%** 提升到 **66.5%**；误差 ≤1% 的从 13.9% 提升到 48.2%。

**⚠️ 但补偿不是全天候都有效**，按流量区间拆开看：

| 真值区间          | 补偿前中位 | 补偿后中位     | 改善倍数           |
| ------------- | ----- | --------- | -------------- |
| < 12 L/s      | 4.26% | 4.67%     | 0.91（略差）       |
| 12 ~ 15       | 3.00% | 6.72%     | **0.45（明显变差）** |
| **15 ~ 17**   | 4.31% | **0.79%** | **5.46 ★**     |
| **17 ~ 18.5** | 2.71% | **0.60%** | **4.53 ★**     |
| > 18.5        | 1.15% | 0.98%     | 1.17           |

**收益全部集中在主力流量区（15 ~ 18.5 L/s，占 72.5% 样本）；12 ~ 15 L/s 段反而变差。**

## 六、几个关键点

### ★ 1. 必须卡掉真值的极端尖峰

`rsm_config.py` 里的 `Q_TRUE_MAX = 60.0` **不要删**。

原因：`体积流量_首信` 的中位数只有 16.97，但最大值高达 **3774**。  
这些尖峰只占全部数据的 **0.17%**，却贡献了 **99% 的平方误差**。  
一旦不卡：

| 指标                  | 不卡尖峰  | 卡尖峰       |
| ------------------- | ----- | --------- |
| corr(液体_光量子, 体积_首信) | 0.083 | **0.809** |
| R²(体积_首信 ~ √Δp)     | 0.008 | **0.722** |

R² 会从 0.6 直接掉到 0.01，得出的结论会完全反过来。

### 2. 为什么按时间切分，不随机打乱？

流量是连续变化的，相邻两个点高度相似。  
如果随机打乱，训练集里会出现测试点"隔壁"的数据 → **数据泄漏**，指标虚高，上线就失效。  
所以 `split_by_time()` 严格按时间先后切：前 70% 训练、中 15% 验证、后 15% 测试。

### 3. 为什么不用「强制过原点」的写法？

物理上，差压式流量计在 Δp = 0 时流量确实应该为 0，  
所以常见的做法是把模型写成 `Q = 基函数 × √Δp`，强制过原点。

**但在本数据集上实测发现这是个陷阱：**

| 写法           | 同批次测试 R²      | 留一天交叉验证（最差天）       |
| ------------ | ------------- | ------------------ |
| 强制过原点 `×√Δp` | **0.604**（更好） | 7.49%，**最差天 66%**  |
| 标准全二次（本代码）   | 0.568         | **2.28%，最差天 7.6%** |

原因：强制过原点等于**剥夺了模型的直流偏置能力**。  
一旦某天的基线整体偏移，它只能靠扭曲斜率去凑，低流量日误差就会爆炸。

→ 所以本代码采用 **标准全二次** 写法。（这个结论本身也是个不错的论文素材。）

### 4. 为什么用「中位误差」而不是 MSE？

MSE 和裸相关系数都会被少数极端值主导，掩盖主流量区间（中位段）的真实表现。  
用中位误差 / p90 更稳健，也更符合工程直觉。
